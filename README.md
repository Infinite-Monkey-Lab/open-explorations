# 🌱 开放探索项目

这里展示仍在探索、快速试验或暂未归入其他分类的项目。此仓库作为索引；项目主页、源码与讨论保留在各自的独立仓库。

## 项目列表

目前还没有收录项目，欢迎分享新的想法、原型和实验。

## 收录字段规范

每个项目条目应链接到独立主页（如已有），并说明问题背景、当前状态、维护者、下一步、希望获得的帮助和许可证信息。未知信息标注“待确认”，不要推测维护状态或许可证。

新增或更新条目时，可复制[项目条目模板](https://github.com/Infinite-Monkey-Lab/.github/blob/main/PROJECT_ENTRY_TEMPLATE.md)。

## 提交项目

[在组织 Discussions 提交开放探索项目或发起讨论](https://github.com/orgs/Infinite-Monkey-Lab/discussions/new/choose)。请介绍问题背景、当前进展、希望获得的帮助和项目主页（如已有）。
